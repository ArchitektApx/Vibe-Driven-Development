# What an unmatched return means

One resume rather than several, because the miss is rarely the Role being
uncooperative. A hosted Role takes the print path by construction: it sends a
Doorbell only when both its messaging tools are available and the target is
listed in `LOOP.md`, and a subagent fails that test. So the line it prints
unprompted is already a valid `DOORBELL`, and a prefix is what a cooperative
Role adds rather than what you depend on.

A return with no line matching either template is a Role that ended somewhere
its own skill did not plan for. One restatement of the contract covers the Role
that lost track of it; a second miss is not a wording problem, and the user is
the one who can see what went wrong.
